# Fly Brain Stimuli Dataset

## Directory Structure

```
data/stimuli/
├── metadata.json          # Stimulus catalog and descriptions
├── food/                  # Food source images
├── flies/                 # Other fly images
├── predators/             # Predator images (wasps, spiders)
├── patterns/              # (Empty - synthetic patterns generated programmatically)
└── natural/               # Natural scene images
```

## Adding Stimuli

### Image Requirements

- **Format**: PNG or JPG
- **Size**: Any size (automatically resized to 100×100 for processing)
- **Color**: RGB or grayscale (converted to grayscale for motion detection)
- **Naming**: Descriptive names (e.g., `rotting_banana.png`, `wasp_approaching.jpg`)

### Categories

1. **food/** - Food sources flies are attracted to
   - Rotting fruit
   - Sugar sources
   - Fermenting materials
   - Examples: bananas, grapes, sugar water

2. **flies/** - Images of other flies
   - Male flies
   - Female flies
   - Various poses
   - Different angles

3. **predators/** - Natural predators
   - Wasps
   - Spiders
   - Praying mantis
   - Other threats

4. **patterns/** - Synthetic (generated by code)
   - Drifting gratings (motion in 4 directions)
   - Looming stimuli (expanding circles)
   - Flickering patterns
   - No images needed here - generated programmatically

5. **natural/** - Environmental scenes
   - Flowers
   - Leaves
   - Tree bark
   - General landscapes

## How to Add Images

1. Save images to appropriate category folder
2. Update `metadata.json` with image details (optional but recommended)
3. Restart the simulation - images automatically loaded

Example metadata entry:

```json
"banana_ripe.png": {
  "category": "food",
  "description": "Ripe banana on white background",
  "motion": false,
  "expected_response": "approach"
}
```

## Expected Responses

Based on fly neuroscience literature:

- **Food**: Moderate arousal, approach behavior, memory encoding likely
- **Flies**: Complex social responses, depends on context (mating vs. competition)
- **Predators**: High alert, rapid coherence increase, avoidance/freezing
- **Motion patterns**: Directional selectivity, T4/T5 neuron activation
- **Natural scenes**: Variable, depends on features present

## Using the System

The StimulusGenerator will:
1. Load all images from category folders
2. Generate synthetic patterns programmatically
3. Present stimuli in random or sequential order
4. Add inter-stimulus intervals (blank periods) for baseline recovery
5. Track which stimulus is being shown for response correlation

No images? No problem! The system generates 15 synthetic motion patterns automatically.
