## Phase 2: Prior Art Search (Days 8-14)

### Day 8-10: Attorney Conducts Search

- [ ] Attorney searches USPTO database
- [ ] Attorney searches international databases (EPO, WIPO, JPO)
- [ ] Attorney searches academic literature (arXiv, PubMed, Google Scholar)
- [ ] You provide list of known related work

### Day 11-12: Review Search Results

- [ ] **Prior art analysis report received**
  - Date received: _______________
  - Number of similar patents found: _______________
  - Number of blocking patents: _______________
  - Patentability assessment: Strong / Medium / Weak

- [ ] Review each similar patent with attorney:
  - [ ] Patent 1: _______________ - Distinguishable? Yes / No
  - [ ] Patent 2: _______________ - Distinguishable? Yes / No
  - [ ] Patent 3: _______________ - Distinguishable? Yes / No
  
- [ ] Decision on proceeding:
  - [ ] Proceed with all 3 patents
  - [ ] Proceed with 2 patents (which: _______________)
  - [ ] Proceed with 1 patent (which: _______________)
  - [ ] Refine claims to avoid prior art
  - [ ] Do not proceed (rare - only if blocking patents found)

### Day 13-14: Refine Applications

- [ ] Attorney drafts refined claims avoiding prior art
- [ ] Attorney adds explicit distinctions from similar patents
- [ ] Attorney prepares professional drawings/figures
- [ ] You review and approve drafts

## Phase 5: Post-Filing Activities (Days 26-365)

### Immediate (Days 26-30)

- [ ] **Press release (optional)**:
  - [ ] Draft press release
  - [ ] Submit to PR wire services
  - [ ] Contact tech journalists
  - [ ] Post on social media (LinkedIn, Twitter)

- [ ] **Journal submission**:
  - [ ] Submit manuscript to Nature Communications
  - [ ] Include "Patent Pending" notice in manuscript
  - [ ] Submit supplementary materials

- [ ] **Preprint posting**:
  - [ ] Post to bioRxiv
  - [ ] Include "Patent Pending" notice
  - [ ] Share on social media

### Short-Term (Days 31-90)

- [ ] **Early licensing outreach**:
  - [ ] Prepare pitch deck (10-15 slides)
  - [ ] Identify 10-20 target companies
  - [ ] Send introductory emails with NDA
  - [ ] Schedule exploratory calls

- [ ] **Conference submissions**:
  - [ ] NeurIPS (deadline: May)
  - [ ] CVPR (deadline: November)
  - [ ] Computational Neuroscience conferences

- [ ] **Build patent portfolio evidence**:
  - [ ] Continue research demonstrating commercial value
  - [ ] Collect user testimonials (if software released)
  - [ ] Gather performance metrics

### Medium-Term (Days 91-270)

- [ ] **Prepare full utility applications**:
  - [ ] Schedule meeting with attorney (month 6)
  - [ ] Refine claims based on early feedback
  - [ ] Add dependent claims for broader protection
  - [ ] Prepare formal drawings (patent illustrator)

- [ ] **International strategy**:
  - [ ] Decide on PCT filing (covers 150+ countries)
  - [ ] Identify priority countries (EU, China, Japan, Korea)
  - [ ] Budget for international costs ($50K-100K)

- [ ] **Licensing progress**:
  - [ ] Track company interest (maintain spreadsheet)
  - [ ] Negotiate term sheets with interested parties
  - [ ] Engage licensing attorney if needed

## Final Pre-Filing Checklist

**Before you file, ensure ALL boxes are checked:**

- [ ] Attorney selected and engaged
- [ ] Prior art search completed
- [ ] All 3 patent applications reviewed and approved
- [ ] Inventor declarations signed
- [ ] Funding secured for filing costs
- [ ] Post-filing communication plan established
- [ ] 12-month utility deadline calendar reminder set
- [ ] Attorney authorized to file via signed Power of Attorney
- [ ] Ready to proceed with filing

**If all boxes are checked, you're ready to file! Good luck! 🚀**

---

**Remember:** Time is critical. File within 30-60 days to preserve international rights and prevent competitors from filing first.
